# 학기 To-do 화면 개선

## 서버 다국어 콘텐츠 관리

- 학기명과 각 주차 안내의 제목·설명은 Firestore의 언어별 map으로 관리한다. 표준 필드는 `ko`, `en`, `zh_Hans`이며, 전환 중인 앱과의 호환을 위해 관리 화면 저장 시 동일한 중국어 값을 `zh`에도 함께 기록한다.
- 운영자는 앱의 `학기 To-do 관리`에서 한국어·영어·간체 중국어 값을 각각 입력할 수 있다. 중국어 UI는 `zh_Hans_CN` → `zh_Hans` → `zh` 순으로 기존 서버 데이터도 읽으며, 중국어 값이 아직 없는 기존 문서는 영어를 fallback으로 표시해 빈 제목이나 빈 설명이 생기지 않는다.
- 설명에 언어별 URL을 함께 입력하면 각 언어 설명에서 해당 링크를 열 수 있다. 대표 이미지와 별도 `자세히 보기` 연결은 기존 공통 필드를 그대로 사용하며, 완료 상태·개인 할 일·알림 데이터에는 영향을 주지 않는다.

최신 통합 목록 변경과 검증 결과는 [통합 목록 후속 기록](semester_todo_unified_20260914.md)을 참고하세요. 아래는 탭 분리 당시의 이력입니다.

후속 수정/배포 상태는 [2026-09-14 후속 기록](snack_chat_todo_followup_20260914.md)을 참고하세요. 아래 테스트 결과는 이전 작업 시점의 기록이며 후속 수정에서는 사용자 요청에 따라 테스트·앱 빌드를 실행하지 않았습니다.

## 변경 범위

- 화면: 작은 학기/대상 한 줄, 개인/가이드 탭, 날짜 범위와 개인 잔여 수만 표시. 주차 이동과 목록별 스크롤 유지, 현재 주 복귀, 하단 고정 추가 버튼.
- 개인 목록: 체크/편집/알림의 별도 터치 영역, 완료 취소, 이전 주 항목 접기, 같은 항목 이동 및 숨김/복구.
- 가이드: 원래 주차에서 안내/추천 표시. 설명은 요약+상세로 분리하고 완료 기록은 상세에서 확인/취소 가능. 출처/유효기간/최근 확인일은 현재 데이터에 없으므로 생성하지 않음. 저장된 기한과 대상, 기존 연결 동작만 사용.
- 등록: 제목만으로 저장 가능, 날짜/주차/시간/기타 설정은 추가 옵션. 새 항목의 알림은 OFF.

## 보존 및 저장 정책

- 현재 계정별 SharedPreferences 개인 목록과 Firestore 안내/완료 기록 구조 유지. 데이터 초기화·서버 마이그레이션 없음.
- 선택한 주차에 배정된 개인 항목만 잔여 수에 포함. 이전 주 항목, 숨김, 미추가 가이드는 제외. 완료 기록은 삭제하지 않음.
- 가이드 추가 시 선택적으로 `sourceGuideKey`를 개인 레코드에 보관. 기존 필드 없는 항목도 그대로 읽음. 안내의 주차 ID+항목 ID와 대상 주차로 중복 방지하며 제목이 같은 별도 기록을 합치지 않음.
- 이동은 ID/기한/메모/중요도/완료 기록/알림 ON·OFF를 유지하고 주차·알림 시작일만 갱신. 동일 안내가 목적 주차에 이미 있으면 병합하지 않고 실패 처리.
- 숨김은 기존 `archived` 필드 사용. 완료 처리와 별개이며 원래 주차로 복구 가능.
- 기기 목록 읽기-수정-쓰기를 직렬화. 계정 변경 후 대기 요청을 거부. 예약 실패 시 해당 변경 전 저장 상태와 예약을 복구 시도하며 OS 복구까지 실패하면 기존 재조회 동기화 경로에서 재시도.
- 기본 오전 8시 및 기존 사용자 지정 시각, 전체/항목별 설정과 안정적인 계정+항목 알림 ID 유지. 완료/숨김은 해당 예약만 취소; 복구는 기존 설정이 ON일 때만 재예약. 오래된 화면 스냅샷으로 예약을 되살리지 않도록 동기화 시 최신 로컬 상태 사용.
- 조회/로컬 해석 실패를 빈 목록으로 취급하지 않음. 실패한 기존 데이터 가져오기는 완료 표시하지 않고 재조회로 재시도.
- 채팅·푸시·배지·서버 Functions/Rules/인덱스와 공통 알림 서비스는 이번 작업에서 수정하지 않음.

## 검증과 적용

- 대상 모델/서비스/컨트롤러 테스트: 중복 추가, 다른 주/목적의 동명 항목 보존, 이동·숨김·복구·완료와 알림 호출, 실패 복구, 동시 변경, 계정 전환, 조회 실패, 기존 기록, OFF 상태 보존, 지연 동기화.
- Widget 테스트: 한/영/중, 폭 320/360/412, 글씨 1x/2x, 키보드/하단 여백, 가이드 상세, 주차 및 스크롤 유지, 제목만 저장, 완료 되돌리기, 오류 표시. 360px 한국어 렌더링도 별도 확인.
- 미확인: 실제 Android/iOS의 예약 알림 발송 시각·권한 거부·재부팅·배터리 절약, 운영 계정의 레거시 데이터 가져오기. 테스트는 격리된 저장소와 알림 대역을 사용하며 실기기 발송을 보장하지 않음.
- 앱 변경만 필요. 이번 작업을 위한 Firebase 배포/인덱스 추가/데이터 반영 작업 없음. 배포는 수행하지 않음.
- 복귀 시 To-do 관련 화면/컨트롤러/서비스/모델 변경만 되돌리고 SharedPreferences 및 Firestore 기록은 삭제하지 말 것. 이전 앱도 기존 필드로 읽을 수 있지만 새 숨김 목록과 복구 UI는 제공하지 않음.
