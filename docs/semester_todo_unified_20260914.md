# 학기 To-do 통합 목록 — 2026-09-14

이 문서는 개인/가이드 탭을 분리했던 이전 개선 기록보다 우선합니다.

## 화면

- 두 탭과 가이드 추가 유도 문구 제거. 선택 주의 개인 항목 + 실행형 가이드를 같은 행으로 표시.
- 실제 데이터의 `required`는 체크 대상, `notice`와 `recommendation`은 참고 안내로 표시. 제목 문장만 보고 정보 항목을 강제 할 일로 바꾸지 않음.
- KST·첫 부분 주차/이후 월~일 정책을 이용한 별도 `calendarWeek`로 실제 현재 주 배지 표시. 선택은 밑줄, 현재 주는 글자 배지로 구분. 운영자 override를 사용하는 다른 기존 소비자는 변경하지 않음.
- 앱 복귀 시 실제 주 표시만 갱신. 선택 주차는 유지. 학기 밖에서는 배지/현재 주 복귀 버튼 없음.
- 이전 주 미완료는 위에 기본 펼침(최대 3개 + 더 보기). 가까운 주 우선이며 명시적인 `carryOver` 항목만 표시. 원래 주차와 저장된 기한 표시, 체크는 원본에 적용.
- 이번 주/선택 주 할 일 제목, 한 번의 날짜 범위와 잔여 수. 개인 + 실행형 가이드만 집계; 정보/이전 주/숨김 제외. 항목 없는 상태와 모두 완료를 구분.
- 완료 영역 펼침·취소, 즉시 Undo, 고정 추가 버튼, 개인 상세 편집/알림/숨김 복구 및 기존 입력 옵션 유지.

## 데이터·동시성·알림

- 개인 데이터는 기존 계정별 SharedPreferences, 가이드는 기존 사용자별 `todoProgress` 문서 사용. ID/원래 주차 변경·데이터 삭제·서버 마이그레이션 없음.
- `sourceGuideKey=weekId/taskId`로 원본 가이드 중복 표시 억제. 제목으로 병합하지 않음. 숨긴/옮긴 연결 항목도 원본이 다시 나타나지 않도록 처리.
- 예전 완료 가이드와 미완료 개인 사본이 연결된 경우 기존 완료 기록을 우선 보존. 사용자가 이후 직접 체크/취소한 의도는 선택적 로컬 필드 `guideCompletionHandled`로 기록하여 오래된 가이드 완료 기록이 취소를 다시 덮지 않음. 기존 앱은 필드를 무시하고 기존 데이터 필드를 읽을 수 있음. 다운그레이드 앱의 편집은 새 필드를 보존하지 않을 수 있으므로 다운그레이드 편집 정합성은 보장하지 않음.
- 가이드별 저장 잠금/실패 원복, 늦은 새로고침 결과로 성공한 체크를 덮지 않는 revision 보호. 개인 저장 실패는 호출자에게 전파하여 성공 안내를 표시하지 않음.
- 조회/새로고침에서 전체 알림 sync 호출 제거. 가이드를 표시하거나 체크해도 개인 할 일/예약 생성 없음. 기존 레거시 데이터의 1회 가져오기는 유지하되 가이드를 개인 데이터로 복제하지 않음.
- 기존 개인 저장 큐·예약 ID·오전 8시/사용자 지정 시각·전체/항목 설정·실패 시 저장/예약 복구 경로 유지. 앱의 기존 시작/언어 변경 알림 복원 경로는 유지.
