## 확인된 원인과 범위

- 운영 Functions 목록에 `querySnackChatMessages`, `getSnackChatMessageContext`, `getSnackChatMentionCandidates`, `validateSnackChatMentions`가 없었음. 앱에는 호출 경로가 이미 존재하여 검색과 참여자 조회가 실패할 수밖에 없는 배포 누락을 확인.
- 운영 Firestore Rules는 저장소 HEAD와 달랐으며 멘션 필드를 허용하지 않았음. 저장소 전체 Rules를 배포하지 않고 **실제 운영 규칙에 멘션 증명 검증과 선택적 필드 허용만** 추가.
- 학기 `2026_fall`은 active이며 공개 주차 및 주차 조회 인덱스 READY를 확인. To-do 데이터 시딩/삭제/마이그레이션 배포는 하지 않음.
- To-do 코드에는 과거 서버 기록 조회 실패가 신규 로컬 할 일 추가까지 막는 경로, 알림 OFF 신규 저장이 불필요한 OS 알림 초기화 실패 때문에 취소되는 경로가 있었음. 사용자의 기기 오류 로그는 확보하지 않았으므로 모든 To-do 장애 원인이 이것이라고 단정하지 않음.

## 변경

- 멘션: Android 키보드가 `@` 자체를 composing으로 표시해도 목록을 열도록 조정. 한글/중국어 이름 조합은 그대로 유지. 계정별 참여자 캐시 구분, 늦은 이전 목록 숨김, 조회 실패 재시도·검색 불일치 안내, 충분한 목록 높이와 터치 영역, 선택 뒤 입력 포커스 유지.
- 검색: 권한/로그인/서비스 미배포 오류를 일반 실패와 구분하여 표시. 검색 범위·읽음·미읽음·실시간 송수신 정책 변경 없음.
- To-do: 서버에서 확정한 과거 기록만 이전 완료로 표시. 8초 조회 제한 후 실패 시 경고를 유지하면서 로컬 추가는 허용하고, 이전 기록 조회는 재시도. 안내 완료 기록 조회 실패도 개인 할 일 탭과 분리. 알림 OFF 신규 항목은 OS 예약을 생성하지 않음. 기존 ON 항목의 변경/숨김/완료 취소·복구 정책과 기본 오전 8시 유지.
- 스타일: To-do 내부 테마만 흰색/중성색과 기존 포스트 작성 화면 계열의 폰트로 명시. 기본 Material 보라색 primary/container/tint 유입 차단. 전체 알림 안내 글자만 13px 수준·중간 굵기로 정리. 다른 화면의 공통 테마는 수정하지 않음.

## 확인하지 않은 것

- 사용자 요청에 따라 앱 빌드, 자동 테스트, 실기기 테스트는 실행하지 않음. 테스트 코드의 기대값만 새 동작에 맞춰 갱신. 코드 포맷/문법 처리와 변경 공백 확인만 수행.
- Firebase 배포 자체에 필수인 TypeScript 변환 및 Rules 컴파일은 실행됨.
- 실제 사용자 로그인 상태에서 검색/멘션 저장, 기기별 알림 권한·예약 발송은 미확인. 운영 사용자 대화/할 일을 변경하는 검증은 하지 않음.
- UI 및 로컬 동작 수정은 새 앱 설치가 필요. 검색 서버 누락 해소는 기존 해당 호출 앱에도 적용됨.
- 멘션 증명의 TTL 정리 설정은 미확인. 증명 만료 거절은 TTL과 별개로 Rules에서 수행됨.

## 복귀

새 멘션 UI 사용자가 있을 때 규칙을 먼저 제거하면 멘션 전송이 거절됨. 필요 시 클라이언트 `SNACK_CHAT_MENTIONS=false`로 신규 선택을 먼저 비활성화하고 callable/선택적 필드 호환은 유지. 전체 규칙을 이전 릴리스로 복구하려면 다른 운영 변경이 없는지 먼저 확인. 어떤 복귀에서도 사용자 할 일, 완료 기록, 알림 설정, 채팅 데이터를 초기화하지 않음.
