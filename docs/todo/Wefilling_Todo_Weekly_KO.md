# 위필링 | 주차별 To-do 콘텐츠 확정안

원문: ERICA 2026-2 OT 한·중·영 합본(161쪽). 16주는 기존 앱의 주차 구성입니다. 생활 안내의 배치 주차는 편집상 권장 시점이며, 학교가 정한 마감일이 아닙니다. 날짜가 정해진 안내는 본문에 실제 기간을 명시했습니다. 현재 기준일은 2026-09-21이며 1~3주차는 과거 안내입니다. 학교 일정은 변경될 수 있으며 실제 신청은 해당 학교·기관에서 진행합니다.
